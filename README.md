# 🕉️ Vighnaharta Mitra Mandal Portal

A modern MERN Stack web application built for **Shri Vighnaharta Mitra Mandal** to manage festival activities digitally.

## 🌟 Features

- 🏠 Beautiful Responsive Homepage
- 📅 Event Management
- 🖼️ Gallery
- 📢 Announcements
- 💰 Donation Page
- 📖 Ganesh Mantras & Atharvashirsha
- 🌙 Dark / ☀️ Light Theme
- 🌐 Marathi & English Language Support
- 🔐 Admin Login & Dashboard

---

## 🛠️ Tech Stack

### Frontend
- React.js
- React Router
- CSS
- Axios

### Backend
- Node.js
- Express.js

### Database
- MongoDB Atlas

## 🚀 Installation

Clone the repository

```bash
git clone https://github.com/Ganeshjoshi08/vighnaharta-ganesh-mandal-Final.git
```

Install dependencies

```bash
cd frontend
npm install

cd ../backend
npm install
```

Run Backend

```bash
npm start
```

Run Frontend

```bash
npm run dev
```
